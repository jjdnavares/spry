# Generated Content DocType

This DocType stores AI-generated content created through the Writer module.

## Fields

- **Title**: Title of the generated content
- **Prompt**: The prompt used to generate the content
- **Generated Text**: The actual content generated by the LLM
- **Keyword**: Main keyword used for generation
- **Tone**: The tone selected for content generation
- **Provider**: LLM provider used (e.g., OpenAI, Anthropic)
- **Model**: The specific model name used for generation
- **Content Type**: Type of content generated (e.g., Article, Blog Post, Social Media)
- **User**: Link to the user who generated the content

## Features

- Automatic user assignment on creation
- Copy to clipboard functionality
- Track changes enabled
- Organized sections for better UX

## Permissions

- System Manager: Full access
- Custom roles can be configured via Role Permission Manager

## Usage

Access the Generated Content form through:
1. Writer module in the app screen
2. Direct navigation to `/app/generated-content`
3. API endpoints for programmatic access
