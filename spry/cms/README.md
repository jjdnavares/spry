# CMS Module

The CMS (Content Management System) module provides comprehensive website and content management capabilities within Spry.

## Features

- Website and page management
- Dynamic content blocks
- Media library and asset management
- Theme and template system
- SEO and metadata management
- Multi-site support
- Content publishing workflows

## Structure

- `doctype/` - DocTypes for CMS entities (Pages, Posts, Media, etc.)
- `api/` - API endpoints for CMS operations
- `templates/` - Jinja templates for rendering
- `workspace/` - Workspace configuration
- `dashboard_chart/` - Analytics and reporting charts
- `report/` - Custom reports
- `www/` - Web pages and routes

## Getting Started

This module provides a complete CMS solution integrated with Spry's workflow automation and AI capabilities.
